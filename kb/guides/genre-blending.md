# Genre blending: carrying 7 or 8 genres in one story

Source: `research/07` part 1. Template: `../templates/story-bible.md`. Rules: R-050 to R-056.

## 1. Principle

One spine, the rest flavours. The spine answers three questions: what the audience wants to happen, what failure looks like, how it usually ends. If two genres both answer them, the result is two stories on one page. Flavours colour scenes through a set piece, a prop, a dialogue register, a musical grammar or an ending type. The count "7 or 8" is the owner's creative choice; no source measures how many genres an audience can hold [S research/07].

## 2. Method (run in order; each step is a line in the story bible)

1. Name the spine: three lines (expect, failure, ending).
2. List the 7 or 8 genres; for each, the single convention it brings (see `genres.md`).
3. Assign each genre one placement: spine, world flavour, character register, or arc lead. None unassigned; one spine.
4. Set the tonal range: 3 to 5 moods; per episode the opening and closing mood.
5. Payoff rule: each major payoff names its mood; comedy sits in set-ups, not payoffs, unless the blend is the scene's point.
6. Declare intent: one line per deliberate shift; if it cannot be written, cut the shift.
7. Name the heart: the one emotional thread that never changes mood; every episode touches it.
8. Two-spines check per arc.
9. Test on one full episode; if the audience would need a note to follow the shifts, step 6 failed.

## 3. Placement defaults for Story-Wrap [S research/07, J]

- One spine for the whole series.
- One flavour genre per world (strongest way to keep 7 or 8 apart; Avatar ties each nation to a cultural and tonal palette).
- One genre register per main character (Cowboy Bebop works this way; the bounty-hunter premise keeps them in one frame).
- Arcs choose which flavour leads.
- One shared power rule across worlds (Sanderson's third law), so the worlds read as related.

## 4. Tone control

- Set the range early (practitioner advice, not a study).
- Keep the big moments serious.
- Structure softens shifts: Australia felt jarring at feature length while the restructured miniseries felt cohesive [S https://www.vidlit.com/articles/how-to-create-a-consistent-story-tone-and-why-it-matters/]. For short episodes: one tonal mode per episode, each set up by the previous one. [J]
- Whiplash needs a signal of intent, and repetition turns it into rhythm: the Daniels on Everything Everywhere All at Once [S https://chicagomaroon.com/33092/artsandculture/everything-daniels-everywhere/ , https://newsweek.com/everything-everywhere-all-once-interview-daniels-son-lux-1706129]. Critics split on whether it worked.

## 6. Failure signs

Two spines; shifts without an intent line; a payoff joke; an episode whose opening mood is not set up; a heart line that changes by mood; one world carrying several flavours with no rule.
